# scored

AI 코딩 세션의 오늘 하루를 스탯 카드로 만들어 줍니다. **분석은 전부 내 컴퓨터에서** 일어나고, 대화 원문은 어디에도 올라가지 않습니다.

```bash
npx @jong-yeon/scored
```

터미널에서 한 줄이면 끝입니다. 설치도 로그인도 없습니다.

## 무슨 일이 일어나나

1. `~/.claude/projects`의 세션 기록(JSONL)을 **읽기만** 합니다
2. 이 컴퓨터에서 집계합니다 — 프롬프트 수, 세션 수, 토큰, 활동 시간, 많이 쓴 도구, 자주 쓴 문장
3. 집계된 **숫자만** 압축해 URL 조각(`#` 뒤)에 담아 `scored.kr`로 브라우저를 엽니다
4. 오늘 대화 전체는 `~/.scored/{날짜}.html`로 저장하고 두 번째 탭으로 엽니다

## 네트워크로 나가는 것

**아무것도 없습니다.** 이 CLI는 네트워크 호출을 하지 않습니다 (런타임 의존성 0 — Node 내장 모듈만 씁니다).

성적표 URL의 `#` 뒤 조각은 **브라우저가 서버로 전송하지 않는** 부분입니다. 대화 원문·파일 경로·사용자명은 이 조각에 들어가지 않습니다. 들어가는 건 집계된 숫자와, 자주 쓴 문장(2회 이상 반복된 것 중 상위 3개)·단어(상위 10개)입니다. `sk-`·`ghp_`·`AKIA`·`Bearer ` 같은 자격증명 패턴이 포함된 문장·단어는 제외됩니다.

## 디스크에 쓰는 것

`~/.scored/{날짜}.html` 하나뿐입니다. 권한 `0600`(본인만 읽기), **최근 7일치만 보관**하고 오래된 건 자동으로 지웁니다. 삭제 대상은 `~/.scored/` 바로 아래의 `YYYY-MM-DD.html` 이름과 정확히 일치하는 일반 파일뿐이라, 그 폴더에 둔 다른 파일은 건드리지 않습니다.

전부 지우려면:

```bash
rm -rf ~/.scored
```
