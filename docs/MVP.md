# MVP 기획서 — 바이브 성적표 (Day 2, 2026-08-13 / **v3 확정** — grill Q1~Q11 통과, 기록: docs/grill-log.md)

> `npx scored` 한 줄이면 AI 코딩 세션 데이터(`~/.claude/projects/*.jsonl`)를
> **내 머신에서** 분석해 대시보드 + 재미 성적표를 생성. 무업로드 · 비로그인 · 무백엔드.

## 한 줄 가치

"내가 **오늘** Claude Code를 어떻게 썼는지"를 **스탯 카드(지표 6줄 + 오늘의 유형 + 등급 뱃지)** 와 그 아래 대시보드로 보여주고, 자랑하고 싶게 만든다.
(은유 = GitHub Readme Stats: 지표를 보여주면서 등급을 매기는 느낌. 실용 = 지표·타임라인·7일 추이, 재미 = 오늘의 유형·문구·공개 연출 — 재미를 빼도 지표로 선다. **2026-08-16 grill로 "하루 단위·지표 중심"으로 재정의**, 이전 "기간 전체 성적 매기기"에서 변경)

## 데이터 흐름 (v3 확정 — npx 진입 + 웹 승인)

1. 랜딩에서 `npx scored` 복사 → 터미널 실행
2. CLI(Node, 무의존성 지향)가 `~/.claude/projects/*.jsonl` **자동 탐색·파싱** — 사용자가 숨김 폴더 찾을 필요 없음. **대상 = 마지막 활동일 하루**(오늘 활동 있으면 오늘, 하루 경계 로컬 05:00) + 최근 7일 컨텍스트
3. 집계 결과 JSON(수 KB)을 압축 인코딩해 `scored.kr/report#<data>`로 브라우저 자동 오픈 (도메인 `scored.kr` — 2026-08-15 구매 완료, 레포명 `scored`와 통일)
4. 웹은 URL 해시에서 데이터를 읽어 렌더링 — **해시는 서버로 전송되지 않는다** = 무업로드 유지
4-1. **로컬 대화 리포트**: CLI가 그날 대화 전체(내 프롬프트 + AI 답변, 세션별)를 `~/.scored/YYYY-MM-DD.html`(자체 완결 정적 파일)로 만들어 두 번째 탭으로 연다 — 원문은 URL·서버 어디에도 안 실리고 내 디스크에만. (2026-08-16 grill Q19: URL은 하루 대화 45k~110k자를 못 싣고(예산 8k), https→localhost 서버는 Safari 차단·Chrome 권한 팝업이라 로컬 파일로 확정)
5. 공유: 카드 이미지 저장 + 결과 링크(해시 포함 URL 그대로 = 공유 링크 공짜). 동적 OG만 쿼리 파라미터 필요 → **공유 버튼 클릭 시에만** 카드 요약 스탯을 쿼리로 변환 (SCR-6에 고지)

원문 대화 내용은 URL·서버에 싣지 않는다(용량 + 공유 시 프롬프트 원문 유출 사고 방지). 원문 열람은 **로컬 파일(4-1)로만**.
웹은 **집계 데이터만** — 하이라이트(가장 많이 쓴 문장 ≤3·단어 ≤10, 빈도 집계)까지 허용.

**하이라이트 웹 승인 방식 (grill Q7 확정)**: 결과 페이지 진입 즉시 주소창 URL에서 하이라이트 데이터 제거(`history.replaceState`, 데이터는 메모리 유지) → 성적표 화면에서 실물 카드로 확인 → 공유 단계(SCR-5)에서 하이라이트 포함/제외 토글 후에야 하이라이트 포함 공유 URL 생성. 주소창 URL 실수 복사로 인한 원문 유출 원천 차단.

**신뢰 장치 (grill Q9·Q11 확정)**: 레포 전체 public(kjjyyy01/scored, 시크릿 스캔 완료) — CLI는 같은 레포 `cli/` 폴더, npm `repository` 필드 연결, 랜딩·런칭 포스트에 GitHub 링크 게시. provenance 배지는 v1.1.

## 추출 지표 (JSONL 파싱 스펙 v1)

실데이터 검증 완료 (2026-08-13, 로컬 263개 세션 파일 샘플링). 파싱 주체는 **CLI(Node)** 로 이동 — 지표 정의는 동일.

**레코드 필터**: `type: user|assistant`만 사용. `isMeta: true`, content가 `<`로 시작(시스템/명령), `isSidechain: true`(서브에이전트)는 프롬프트 카운트에서 제외.

### 성적표 지표 (재미)

| 지표 | 소스 필드 | 성적표 표현 |
|---|---|---|
| 새벽 코딩 지수 | 대상일 프롬프트 중 로컬 00~05시 비율 (하루 경계 05:00) | "새벽 배회자" 유형 입력 |
| 사과 카운트 | assistant text "죄송/미안" 빈도 | "AI가 N번 사과했습니다" |
| 최장 삽질 | 연속 `tool_result.is_error` 구간 | "최장 N연속 에러의 늪" |
| 재시도 지수 | user text "다시/아니/왜" 빈도 | "인내심 등급" |
| 프롬프트 스타일 | 평균 길이, 한 줄 지시 vs 장문 | 유형 판정 입력 |
| 활동 시간 | 첫~마지막 프롬프트 span에서 30분 이상 공백 제외 (분) | 카드 지표 + 등급 입력 + "마라톤 러너" |
| 하이라이트 | 가장 많이 쓴 문장 ≤3(반복 횟수)·단어 ≤10 — 빈도 집계 (2026-08-16 "명대사 발췌"에서 변경) | "\"커밋해줘\" 47번" |

### 대시보드 지표 (실용)

| 지표 | 소스 필드 | 표현 |
|---|---|---|
| 24h 타임라인 | 대상일 시간대별 프롬프트·토큰 (`hourly`) | 타임라인 차트 |
| 7일 추이 | 최근 7일 일별 프롬프트·토큰 (`week`) — "오늘은 이번 주 평균 대비 +N%" | 미니 추이 2줄 |
| 활동 히트맵 | 최근 7일 요일×시간 프롬프트 (`week.heatmap`) | 히트맵 |
| 도구·모델 | `tool_use.name` 카운트 상위 10, 모델별 메시지 수 | 차트·목록 |
| 프롬프트 통계 | 길이 분포·한 줄 비율 + 하이라이트(문장 3·단어 10) | 프롬프트 섹션 |

**오늘의 개발자 유형**: 지표 정규화 최고점 1개로 **6유형 + 폴백 1** 판정 (2026-08-16 grill Q22 초안 확정: 새벽 배회자 / 에러의 늪 탐험가 / "다시요" 장인 / 장문 설교자 / 한 줄 사령관 / 마라톤 러너 / 밸런스 코더) — **매일 바뀌는 게 의도**(별자리 운세). 이름·문구는 Day 7에 다듬음. **등급**: 프롬프트 수·토큰·활동 시간 3지표 고정 임계 커브 → S/A+/A/B+/B/C (활동량 = 높은 등급, 임계는 Day 7 내 30일 로그 → Day 13 게릴라 로그 보정).

**파서 리스크 대응**: 미지 필드 무시(관대한 파싱), 알 수 없는 `type` 스킵, 지표별 독립 실패(부분 생성 허용). 결과 JSON에 스키마 버전 필드 포함(웹-CLI 버전 어긋남 대응).
