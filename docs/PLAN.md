1. **오케스트레이터는 superpowers 1개** — omc는 발동 조건 충족 시에만 교대, 동시 활성화 금지

4. ⚠️ **구간별 지정 스킬은 필수** — 각 Day 표의 "활성화 스킬" 열과 상시 규칙에 지정된 skill·plugin·MCP는 해당 구간의 **작성뿐 아니라 수정·재검토에도 반드시 사용**한다 (기획서 수정 = make-plan, PRD 수정 = make-prd, 스코프 변경 = /grill-me, 설계 판단 = sequential-thinking). 지정 스킬 없이 직접 편집해도 되는 것은 오타·문구 교체·상태 전환뿐. 스킬을 건너뛴 작업은 정합성 미검증으로 간주하고 해당 스킬로 재검증한다 (2026-08-15 추가 — PRD 피드백 반영을 make-prd 없이 수동 편집한 사례에서 명문화)
