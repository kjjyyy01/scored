# 03 용어사전

| 용어 | 정의 | 금지/혼동 주의 |
|---|---|---|
| 성적표 (스탯 카드) | `/report` 상단 카드(SCR-003): 오늘의 유형 + 등급 뱃지 + 날짜 + 지표 6줄 + 유형 문구 — 공유 이미지·OG와 동일 구성 (GitHub Readme Stats 은유, 2026-08-16) | "대시보드"와 혼용 금지 |
| 대시보드 | `/report` 하단 섹션(SCR-004): 24h 타임라인·7일 추이·히트맵·도구·프롬프트 섹션 — 탭이 아니라 스크롤 | "성적표"와 혼용 금지 |
| 결과 페이지 | `/report` 전체 = 한 스크롤 페이지 (SCR-002 연출 → SCR-003 카드 → SCR-004 섹션, SCR-005 오버레이) | — |
| 대상일 | 성적표가 다루는 하루 — 마지막 활동일(오늘 활동 있으면 오늘), 경계 로컬 05:00 (BR-011) | "오늘"과 다를 수 있음 |
| 오늘의 유형 | 대상일 지표로 판정한 개발자 유형 6종+폴백 (BR-010) — 매일 바뀌는 게 의도 | 정체성·누적 아님 |
| 등급 | 프롬프트·토큰·활동 시간 3지표 → S/A+/A/B+/B/C (BR-009) — 활동량 척도 | 실력·효율 평가 아님 |
| 로컬 대화 리포트 | CLI가 `~/.scored/{day}.html`로 생성하는 대상일 대화 전체(세션별 프롬프트+답변) 정적 파일 — 웹·URL·서버 무관 | 공유 불가·의도된 것 |
| 페이로드 | CLI가 생성해 URL 해시에 싣는 집계 JSON (05 스키마) | "원문"과 구분 — 원문은 싣지 않음 |
| 하이라이트 | CLI가 **집계**한 가장 많이 쓴 문장 ≤3(반복 횟수 포함)·단어 ≤10 (BR-005 상한) — 2026-08-16 "명대사 발췌"에서 변경 | 원문 인용이 아니라 빈도 집계 결과 |
| 공개 연출 | SCR-002의 재미 장치 (두구두구·등급 릴) — v1 유일한 재미 장치 | 두 번째 재미 장치 구현 금지 |
| 무업로드 | 페이로드가 서버로 전송되지 않음 (해시는 HTTP 요청에 미포함) | 예외: 공유 버튼 클릭 시 OG 쿼리(BR-006) |
