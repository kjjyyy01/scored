# 05 데이터모델

> DB 없음. 이 문서의 SSOT는 **결과 페이로드 스키마** — CLI(F-007)가 생성하고 웹(`/r`)이 소비하는 유일한 데이터 계약.

## 결과 페이로드 스키마 (v1)

| 경로 | 타입 | 필수 | 제약 |
|---|---|---|---|
| `v` | number | ✓ | 스키마 버전. 현재 `1`. 웹 지원 버전 초과 시 ERR-HASH-002 (BR-003) |
| `generatedAt` | string | ✓ | ISO 8601 |
| `period.from` / `period.to` | string | ✓ | ISO 8601 날짜 — 분석 대상 기간 |
| `stats.sessions` | number | ✓ | 세션 파일 수. `< 3`이면 데이터 부족 (BR-002) |
| `stats.prompts` | number | ✓ | 필터 통과 user 레코드 수 (MVP 레코드 필터 준수) |
| `stats.activeDays` | number | ✓ | 활동일 수 |
| `stats.models` | `{[model]: number}` | ✓ | 모델별 메시지 수 |
| `stats.tokensDaily` | `[["YYYY-MM-DD", number]]` | ✓ | 일별 토큰 합산 (`message.usage`) |
| `stats.heatmap` | `number[7][24]` | ✓ | 요일×시간 활동 버킷 |
| `stats.tools` | `[[name, count]]` | ✓ | 상위 10개만 |
| `fun.nightRatio` | number | ✓ | 00~06시 활동 비율 (0~1) |
| `fun.apologies` | number | ✓ | assistant "죄송/미안" 빈도 |
| `fun.maxErrorStreak` | number | ✓ | 연속 `tool_result.is_error` 최대 구간 |
| `fun.retryScore` | number | ✓ | user "다시/아니/왜" 빈도 |
| `fun.promptStyle.avgLen` | number | ✓ | 프롬프트 평균 길이(자) |
| `fun.promptStyle.oneLinerRatio` | number | ✓ | 한 줄 지시 비율 (0~1) |
| `excerpts` | `[{kind, text, ts}]` | — | 최대 3개, 각 200자 이내, 자격증명 패턴 제외 (BR-005) |

- **유형·등급은 페이로드에 없다** — 웹이 판정한다 (BR-001). CLI는 원시 집계만.
- 크기 목표: 압축 후 8KB 이내 (OQ-004에서 실측 확정).

## 예시

```json
{"v":1,"generatedAt":"2026-08-14T03:00:00Z","period":{"from":"2026-06-01","to":"2026-08-14"},
 "stats":{"sessions":263,"prompts":1840,"activeDays":61,"models":{"claude-fable-5":1520},
  "tokensDaily":[["2026-08-13",120000]],"heatmap":[[0,2,"…"]],"tools":[["Bash",420]]},
 "fun":{"nightRatio":0.31,"apologies":47,"maxErrorStreak":9,"retryScore":83,
  "promptStyle":{"avgLen":42,"oneLinerRatio":0.7}},
 "excerpts":[{"kind":"quote","text":"…","ts":"2026-08-01T02:14:00Z"}]}
```

## 로컬 저장

localStorage 미사용 (v1은 기록 보존 없음 — 재실행이 곧 갱신). 계정·동기화는 20_범위외.
