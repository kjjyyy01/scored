# 05 데이터모델

> DB 없음. 이 문서의 SSOT는 **결과 페이로드 스키마** — CLI(F-007)가 생성하고 웹(`/report`)이 소비하는 유일한 데이터 계약.

## 결과 페이로드 스키마 (v1) — 2026-08-16 재정의: 하루 단위 + 7일 컨텍스트

| 경로 | 타입 | 필수 | 제약 |
|---|---|---|---|
| `v` | number | ✓ | 스키마 버전. 현재 `1`. 웹 지원 버전 초과 시 ERR-HASH-002 (BR-003) |
| `generatedAt` | string | ✓ | ISO 8601 — "HH:MM 기준" 표기 원천 |
| `day` | string | ✓ | 성적표 대상일 `YYYY-MM-DD` — **마지막 활동일**(오늘 활동 있으면 오늘), 하루 경계 **로컬 05:00** (CLI-001 §2) |
| `inProgress` | boolean | ✓ | 대상일이 실행 시점의 "오늘"이면 true → 카드 "진행 중" 배지 (SCR-003) |
| `stats.prompts` | number | ✓ | 대상일 필터 통과 user 프롬프트 수. **`< 10` → 부분 모드** (BR-002) |
| `stats.sessions` | number | ✓ | 대상일에 프롬프트 ≥1개인 세션 파일 수 |
| `stats.tokens` | `{in, out}` | ✓ | 대상일 토큰 — `in` = input+cache_creation+cache_read, `out` = output (중복 제거 후, CLI-001 §3) |
| `stats.activeMinutes` | number | ✓ | 활동 시간(분) = 첫~마지막 프롬프트 span에서 30분 이상 공백 제외 |
| `stats.models` | `{[model]: number}` | ✓ | 대상일 모델별 메시지 수 |
| `stats.tools` | `[[name, count]]` | ✓ | 대상일 도구 호출 상위 10개 |
| `stats.hourly` | `{prompts: number[24], tokens: number[24]}` | ✓ | 대상일 시간대별(로컬 시 0~23) 프롬프트·토큰 — 24h 타임라인 |
| `week.days` | `string[7]` | ✓ | 대상일 포함 최근 7일 `YYYY-MM-DD` (오래된→최근) |
| `week.prompts` / `week.tokens` | `number[7]` | ✓ | 7일 일별 프롬프트·토큰 (활동 없는 날 0) — "이번 주 평균 대비" 비교선 |
| `week.heatmap` | `number[7][24]` | ✓ | 최근 7일 요일(0=일)×시간 프롬프트 수 |
| `fun.nightRatio` | number | ✓ | 대상일 프롬프트 중 로컬 00:00~04:59 비율 (0~1) |
| `fun.apologies` | number | ✓ | 대상일 assistant "죄송/미안" 빈도 |
| `fun.maxErrorStreak` | number | ✓ | 대상일 연속 `tool_result.is_error` 최대 구간 |
| `fun.retryScore` | number | ✓ | 대상일 user "다시/아니/왜" 빈도 |
| `fun.promptStyle.avgLen` | number | ✓ | 대상일 프롬프트 평균 길이(자) |
| `fun.promptStyle.oneLinerRatio` | number | ✓ | 대상일 한 줄 지시 비율 (0~1) |
| `fun.promptStyle.lenBuckets` | `number[5]` | ✓ | 길이 분포 버킷 [<20, <50, <100, <200, ≥200자] — 프롬프트 섹션 |
| `highlights.sentences` | `[[text, count]]` | — | 대상일 가장 많이 쓴 문장 상위 3개(반복 ≥2회, 각 ≤100자), 자격증명 패턴 제외 (BR-005) |
| `highlights.words` | `[[word, count]]` | — | 대상일 가장 많이 쓴 단어 상위 10개 (2자 이상, BR-005) |

- **유형·등급은 페이로드에 없다** — 웹이 판정한다 (BR-001, 규칙 BR-009·BR-010). CLI는 원시 집계만.
- **로컬 대화 리포트 경로는 싣지 않는다** — 사용자명이 포함된 경로가 공유 링크에 실리는 것 방지. 웹은 관례 경로(`~/.scored/{day}.html`)만 안내 (CPY-DASH-001).
- 삭제된 필드(2026-08-16): `period`, `stats.activeDays`, `stats.tokensDaily`, `stats.heatmap`(→ `week.heatmap`).
- 크기 상한: 인코딩(base64url) 후 **8,000자** 이내 — **확정** (OQ-004 실측 2026-08-18: 30일 실로그·하루+7일 스키마·히트맵 포함 → JSON 1,671자 → 인코딩 **1,104자**(URL 1,138자), 하이라이트 제거 시 880자, 최악 근사 ≈1.1K. 상한 대비 여유 7배). 초과 시 CLI가 `highlights`부터 비운다 (CLI-001 REQ-CLI-001).
