# 06 API공통규약

> 서버 API는 동적 OG 1개뿐 (07 참조). 핵심 계약은 **URL 해시 페이로드 규약**이다.

## 해시 페이로드 규약

- 인코딩: `JSON → deflate-raw → base64url` → `scored.kr/report#<data>`
- 해시 프래그먼트는 HTTP 요청에 포함되지 않는다 = 무업로드의 기술적 근거 (SCR-006에서 고지)
- 디코딩 실패 → ERR-HASH-001, 버전 초과 → ERR-HASH-002 (BR-003)
- 버저닝: 페이로드 `v` 필드 (05 참조). URL 경로 버저닝 없음
- 하이라이트 포함 해시는 진입 즉시 주소창에서 제거 (BR-004)
- **진입 출처 쿼리** `?from=cli`: CLI가 여는 URL에만 붙는다 (`scored.kr/report?from=cli#<data>`). 웹은 진입 시 읽어 EVT-RES-001 `entry`를 정하고 BR-004 replaceState로 쿼리도 함께 제거. SCR-005 링크 생성기는 쿼리를 싣지 않는다 → 공유 링크·주소창 복사본은 전부 `entry=link` (2026-08-16 — 킬 크라이테리아 도달률 오염 방지)

## 서버 API 규약 (동적 OG 한정)

- 경로: `/api/og` (GET, 무상태, 무DB)
- 파라미터: 요약 스탯만 — 하이라이트·원문 금지 (BR-006)
- 에러: 어떤 실패든 정적 OG 이미지로 폴백 (ERR-OG-001) — 사용자에게 에러 노출 없음
- 인증·페이징·멱등성 키: 해당 없음
