# 07 API명세

> 엔드포인트 1개. Day 9 컷 1순위 — 컷 시 정적 OG만 사용하며 이 문서 전체가 "범위 외"가 된다.

## GET /api/og

- 구현: `@vercel/og` 엣지 함수. 무DB·무상태.
- 용도: 공유 링크의 OG 미리보기 이미지 (공유가 재미의 1차 전달자 — PLAN)
- 호출 시점: SCR-005에서 공유 버튼 클릭 시에만 쿼리 생성 (MVP 데이터 흐름 5)

| 쿼리 | 타입 | 필수 | 예 |
|---|---|---|---|
| `t` | string | ✓ | 개발자 유형 코드 (Day 7 확정 — OQ-001) |
| `g` | string | ✓ | 등급 (OQ-002) |
| `s1`~`s3` | string | — | 요약 스탯 3개 (라벨:값) |

- 응답: `image/png` 1200×630. 캐시: `immutable` (동일 쿼리 = 동일 이미지)
- 실패: 정적 OG 폴백 (ERR-OG-001)
- 금지: 발췌·원문·PII 쿼리 전달 (BR-006 강제 지점 = SCR-005 URL 생성 코드)
