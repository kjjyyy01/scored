# 07 API명세

> 엔드포인트 1개. **컷 대상 제외 (2026-08-16)** — 공유 링크 미리보기가 재미의 1차 전달자이며 구현 비용 <1일. 실패 시에만 정적 OG 폴백(ERR-OG-001).

## GET /api/og

- 구현: `@vercel/og` 엣지 함수. 무DB·무상태.
- 용도: 공유 링크의 OG 미리보기 이미지 (공유가 재미의 1차 전달자 — PLAN)
- 호출 시점: SCR-005에서 공유 버튼 클릭 시에만 쿼리 생성 (MVP 데이터 흐름 5)

| 쿼리 | 타입 | 필수 | 예 |
|---|---|---|---|
| `t` | string | ✓ | 오늘의 유형 코드 (`night`·`swamp`·`retry`·`long`·`one`·`marathon`·`balance` — 코드↔이름 매핑은 08 §계산 규칙, 2026-08-24 확정) |
| `g` | string | ✓ | 등급 S/A+/A/B+/B/C (BR-009) |
| `d` | string | ✓ | 대상일 `YYYY-MM-DD` (+ `ip=1`이면 진행 중) |
| `p`,`s`,`k`,`m` | number | — | 프롬프트·세션·토큰(in+out)·활동 분 — 카드 지표 ①~④ |
| `tl` | string | — | 최다 도구명 (카드 지표 ⑤) |
| (없음) | — | — | 최다 문장(카드 ⑥)은 **원문이라 OG 금지** (BR-006) — 이미지엔 유형·등급·날짜·숫자 5개·도구만 |

- 응답: `image/png` 1200×630. 캐시: `Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800` — CDN 1일 재사용 + 백그라운드 갱신. `immutable` 금지: 쿼리는 등급 *코드*뿐이라 라벨·디자인(서버 코드) 변경 시 이미지가 달라져야 함 (2026-08-16 수정, BR-001 부작용 검토에서 발견)
- 실패: 정적 OG 폴백 (ERR-OG-001)
- 금지: 하이라이트·원문·PII 쿼리 전달 (BR-006 강제 지점 = SCR-005 URL 생성 코드)
