## 상태전이 (`/report` 결과 페이지)

DB 없음 — 클라이언트 상태 머신만 존재 (enum 1:1 검사 해당 없음).

```mermaid
stateDiagram-v2
    [*] --> Decoding: /report 진입
    Decoding --> Revealing: 디코딩 성공 (BR-004 즉시 실행)
    Decoding --> Error: ERR-HASH-001 | ERR-HASH-002
    Decoding --> Empty: 해시 없음 → 랜딩 유도
    Revealing --> Report: 연출 완료 (스킵 포함)
    Report --> Dashboard: 탭 전환
    Dashboard --> Report: 탭 전환
    Report --> Sharing: 공유 열기 (SCR-005)
    Sharing --> Report: 닫기
```

계산 규칙(유형 판정식·등급 커브)은 Day 7 콘텐츠 제작일에 이 문서에 추가 확정 (OQ-001·OQ-002).
