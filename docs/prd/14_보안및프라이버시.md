# 14 보안·프라이버시

> 무업로드가 제품의 핵심 가치이자 신뢰 장치 — 위반은 버그가 아니라 제품 정체성 훼손.

## 원칙

1. **페이로드 서버 미전송**: 결과 데이터는 URL 해시로만 이동 (06 규약). 서버 로그에 남지 않음.
2. **원문 미포함(URL·서버)**: 대화 원문은 페이로드·URL·서버·GA4 어디에도 싣지 않는다. 하이라이트(빈도 집계)만 BR-005 상한 내에서. 원문 열람은 **로컬 파일**(CLI-001 REQ-CLI-003, `~/.scored/`, 권한 0600)로만 — 공유 불가가 의도(20).
3. **하이라이트 노출 통제**: BR-004 (주소창 즉시 제거 + 공유 시 명시 토글).
4. **OG 쿼리 최소화**: BR-006 (유형·등급·요약 스탯만).
5. **GA4 이벤트에 성적 데이터 금지**: 이벤트 파라미터에 지표 값·하이라이트·경로명을 싣지 않는다 (15 §파라미터 정책).
6. **CLI 시크릿 마스킹**: 자격증명 패턴 하이라이트 제외 (BR-005).
7. **레포 public 유지**: 코드가 곧 증명 (grill Q9·Q11). 시크릿 커밋 금지 (CLAUDE.md).

## 고지 의무

- SCR-006: 처리 방식 + 공유 시 쿼리 전송 범위 + GA4 사용 고지 (PLAN "분석 도구 고지 페이지 무조건 필수").
- 개인정보처리방침·약관: 회원 기능 없음 → 해당 없음 (PLAN Day 15~16 조건 미충족).
