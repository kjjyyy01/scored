## 1. 개요
- **목적:** `~/.claude/projects` 세션 로그에서 **대상일 하루 + 최근 7일 컨텍스트**를 로컬 집계해 05 페이로드를 만들고 `scored.kr/report#<data>`를 브라우저로 연다. 동시에 대상일 **대화 전체를 로컬 HTML 리포트**(`~/.scored/{day}.html`)로 만들어 두 번째 탭으로 연다. 화면 없음 — 깔때기 2→3단계(복사 → 결과 도달)의 유일한 다리. (2026-08-16 grill 반영)
- **구현 기능:** F-007. 위치 `cli/` (같은 레포 — 코드가 곧 증명, 14 §7). 지표 *정의*는 MVP §추출 지표(실데이터 검증 완료)에서 승계 — 승계 후 **이 문서 §3이 집계 규칙의 SSOT**다 (MVP.md는 동결).
- **원칙:** 런타임 의존성 0 (Node 내장 `fs`·`zlib`·`child_process`만). 네트워크 호출 0 (무업로드는 CLI부터 성립).

## 2. 입력 계약
| 항목 | 규칙 |
|---|---|
| 탐색 경로 | `$HOME/.claude/projects/**/*.jsonl` (하위 디렉터리 재귀 — 서브에이전트 트랜스크립트 포함 가능성). 미존재·읽기 실패 → ERR-CLI-001 |
| 레코드 필터 | MVP §레코드 필터 그대로: `type: user\|assistant`만. `isMeta: true`, content가 `<`로 시작, `isSidechain: true`는 **프롬프트 카운트·하이라이트·재시도 지수에서 제외** (토큰·도구·에러 집계에는 포함) |
| 관대한 파싱 | 줄 단위 JSON 파싱 실패·알 수 없는 `type`·필드 누락은 **건너뛴다** (예외 금지 — MVP 파서 리스크). 파싱 가능한 세션 0개 → ERR-CLI-002 |
| 중복 제거 (assistant) | 같은 `message.id`가 여러 줄로 반복될 수 있다 → **`message.id` 기준 1회만** usage·model 집계 (이중 계산 방지). `message.id` 없으면 `uuid` 사용 |
| 중복 제거 (user) | 세션 재개 시 Claude Code가 **직전 대화 전체를 새 `.jsonl`로 복제**하고 이어 쓴다 → user 프롬프트도 **`uuid` 기준 1회만** 집계. 미적용 시 프롬프트가 부풀려진다 (2026-08-19 실측, §2 필터 적용 후: 원시 28개 → 유니크 15개, **46% 부풀림** → 등급 BR-009 인플레) |
| 하루 경계 | **로컬 05:00** — 05:00 이전 프롬프트는 전날 귀속 (새벽 코딩러의 하루가 자정에 끊기지 않게). 모든 "일" 계산(대상일·7일·히트맵)이 이 경계를 쓴다 (BR-011) |
| 대상일 | **마지막 활동일** = 필터 통과 user 프롬프트가 있는 가장 최근 경계일. 실행 시점이 그 경계일 안이면 `inProgress: true`. 옵션 없음(v1) |
| 7일 컨텍스트 | 대상일 포함 최근 7 경계일 — `week.*`. 로그 보관 기본 30일이라 항상 가용 (부족하면 0) |
| 타임존 | 전 버킷은 **CLI 실행 머신의 로컬 타임존** 기준. 웹은 재계산하지 않는다 |
| 세션 정의 | 대상일에 필터 통과 user 프롬프트 ≥1개인 `.jsonl` 파일 중, **프롬프트 `uuid` 집합이 다른 파일의 집합에 완전히 포함되는 파일(재개 복제본)을 제외**한 나머지 파일 수. 집합이 완전히 같은 파일들은 1개로 센다. 리포트(REQ-CLI-003) 세션 블록도 동일 기준 (2026-08-19 실측: 파일 4개 → 실제 대화 2개) |

## 3. 집계 규칙 (05 필드 ↔ 소스) — 별도 표기 없으면 **대상일** 레코드만

|---|---|

| `stats.sessions` | §2 세션 정의 — 재개 복제본 제외 후 남은 파일 수 |

| `stats.tools` | assistant content `tool_use.name` 건수 상위 10개 |
| `stats.hourly.prompts[h]` / `.tokens[h]` | 로컬 시 h(0~23)별 프롬프트 수 / assistant usage 합(in+out — 위 `stats.tokens`와 동일 정의, cache_read 제외) |

| `fun.retryScore` | 필터 통과 user 텍스트에서 `/다시|아니|왜/g` 매치 수 |

## 4. 하이라이트 집계 (BR-005) — 2026-08-16 변경: 명대사 발췌 → 최다 사용 문장·단어
- **문장**: 필터 통과 user 텍스트를 줄 단위로 나눠 정규화(공백 압축·양끝 문장부호 제거) → 동일 문장 빈도 집계 → **반복 ≥2회 중 상위 3개** `[text(≤100자 절단), count]`
- **단어**: 공백 분리 토큰 중 2자 이상·숫자/기호만인 토큰 제외 → 빈도 **상위 10개** `[word, count]`. 불용어 최소 목록·조사 처리 여부는 Day 7 콘텐츠일 확정(OQ-001 범위, 무의존성 유지)
- 텍스트에 BR-005 자격증명 패턴 포함 시 해당 항목 제외. 05 크기 상한 초과 시 `highlights` 전체 제거(REQ-CLI-001 AC-2)
- 발췌 시절 규칙(삽질 직후 프롬프트·재시도 어휘 인용)은 폐기 — 인용은 프라이버시 리스크 대비 재미가 불안정(휴리스틱 의존)

## 5. 기능 요구사항 (P0 — AC 4종)
### REQ-CLI-001: 집계·인코딩·URL 출력 (P0)
- **AC-1 (정상):** Given `~/.claude/projects`에 파싱 가능한 세션 ≥1, When 실행, Then §2·§3 규칙으로 05 페이로드 생성 → 06 규약 인코딩 → 터미널에 URL 전체 출력 (CPY-CLI-001~003)
- **AC-2 (검증 실패):** Given 경로 미존재 → ERR-CLI-001 / 파싱 가능 세션 0개 → ERR-CLI-002. Given 인코딩 결과가 05 크기 상한 초과 → `highlights`를 비우고 1회 재인코딩 후 진행
- **AC-3 (서버 오류):** 해당 없음 (네트워크 호출 0)
- **AC-4 (오프라인):** 정상 동작 — 전 과정 로컬. 브라우저가 페이지를 못 받는 것은 웹 범위 (SCR-002 AC-4)

### REQ-CLI-002: 브라우저 오픈 (P0)
- **AC-1 (정상):** Given URL 생성 완료, When 플랫폼별 명령 실행 (§실행 동작), Then 기본 브라우저에서 `/report` 열림, exit 0
- **AC-2 (검증 실패):** 해당 없음 (입력 없음)
- **AC-3 (spawn 실패):** Given 명령 부재·SSH·컨테이너, Then ERR-CLI-003 — URL은 이미 출력됨, exit 0 (실패로 취급하지 않음)
- **AC-4 (오프라인):** 브라우저는 열리되 페이지 로드 실패 — 웹 범위

### REQ-CLI-003: 로컬 대화 리포트 (P0 — 2026-08-16 grill Q19)
- **AC-1 (정상):** Given 대상일 대화 존재, When 실행, Then `~/.scored/{day}.html` 생성 — **대상일 대화 전체를 세션별로**(세션 = §2 세션 정의, 시작 시각 순) user 프롬프트·assistant 텍스트를 시간순 렌더(아래 렌더 규칙), 자체 완결 정적 HTML(외부 요청 0, 인라인 CSS — DESIGN 토큰 색·서체 폴백), 파일 권한 0600 → 성적표 URL 다음에 **두 번째 탭으로 오픈**. 기존 파일은 덮어씀
- **AC-2 (검증 실패):** Given 디렉터리 생성·쓰기 실패, Then ERR-CLI-004 경고 1줄 후 계속 (성적표는 정상 진행), exit 0
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (오프라인):** 정상 — 파일은 로컬, 열람도 오프라인 가능
- **AC-5 (보관):** Given `~/.scored/`에 7 경계일 밖 리포트 존재, When 실행, Then 범위 밖 `YYYY-MM-DD.html`만 삭제되고 그 외 파일·디렉터리·심볼릭 링크는 보존. 삭제 실패는 무시하고 계속, exit 0
- 원문은 이 파일에만 존재 — 페이로드·URL·서버·GA4 어디에도 실리지 않음 (14 §2, 20). 파일 경로도 페이로드 미포함(05)
