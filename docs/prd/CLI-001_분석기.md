## 1. 개요
- **목적:** `~/.claude/projects` 세션 로그를 로컬에서 집계해 05 페이로드를 만들고, `scored.kr/report#<data>`를 브라우저로 연다. 화면 없음 — 깔때기 2→3단계(복사 → 결과 도달)의 유일한 다리.
- **구현 기능:** F-007. 위치 `cli/` (같은 레포 — 코드가 곧 증명, 14 §7). 지표 *정의*는 MVP §추출 지표(실데이터 검증 완료)에서 승계 — 승계 후 **이 문서 §3이 집계 규칙의 SSOT**다 (MVP.md는 동결).
- **원칙:** 런타임 의존성 0 (Node 내장 `fs`·`zlib`·`child_process`만). 네트워크 호출 0 (무업로드는 CLI부터 성립).

## 2. 입력 계약
| 항목 | 규칙 |
|---|---|
| 탐색 경로 | `$HOME/.claude/projects/**/*.jsonl` (하위 디렉터리 재귀 — 서브에이전트 트랜스크립트 포함 가능성). 미존재·읽기 실패 → ERR-CLI-001 |
| 레코드 필터 | MVP §레코드 필터 그대로: `type: user\|assistant`만. `isMeta: true`, content가 `<`로 시작, `isSidechain: true`는 **프롬프트 카운트·하이라이트·재시도 지수에서 제외** (토큰·도구·에러 집계에는 포함) |
| 관대한 파싱 | 줄 단위 JSON 파싱 실패·알 수 없는 `type`·필드 누락은 **건너뛴다** (예외 금지 — MVP 파서 리스크). 파싱 가능한 세션 0개 → ERR-CLI-002 |
| 중복 제거 | assistant 레코드는 같은 `message.id`가 여러 줄로 반복될 수 있다 → **`message.id` 기준 1회만** usage·model 집계 (이중 계산 방지). `message.id` 없으면 `uuid` 사용 |
| 분석 기간 | v1은 **전체 이력** (옵션 없음). `period.from/to` = 관측된 최소·최대 timestamp의 로컬 날짜 |
| 타임존 | 시간 버킷(`heatmap`·`nightRatio`·`tokensDaily` 일자·`activeDays`)은 **CLI 실행 머신의 로컬 타임존** 기준. 웹은 버킷을 재계산하지 않는다 (05 스키마 변경 없음) |
| 세션 정의 | `stats.sessions` = 필터 통과 user 프롬프트 ≥1개인 `.jsonl` 파일 수 |

## 3. 집계 규칙 (05 필드 ↔ 소스)
| 05 경로 | 규칙 |
|---|---|
| `stats.prompts` | 필터 통과 user 레코드 중 텍스트 content 보유 건 (tool_result만 있는 user 레코드 제외) |
| `stats.activeDays` | 필터 통과 user 프롬프트가 1개 이상인 로컬 날짜 수 |
| `stats.models` | 중복 제거된 assistant `message.model`별 건수 |
| `stats.tokensDaily` | 중복 제거된 assistant `message.usage`의 `input + output + cache_creation_input + cache_read_input` 합을 로컬 날짜별 합산 (체감 "소모량" — 캐시 포함). 값 없는 날은 배열에서 생략 |
| `stats.heatmap` | 필터 통과 user 프롬프트의 로컬 `[요일 0=일][시 0~23]` 카운트 |
| `stats.tools` | assistant content `tool_use.name` 건수 상위 10개 |
| `fun.nightRatio` | 로컬 00:00~05:59 user 프롬프트 ÷ 전체 user 프롬프트 |
| `fun.apologies` | assistant text 블록에서 `/죄송|미안/g` 매치 수 (중복 제거 후) |
| `fun.maxErrorStreak` | 세션 내 시간순 `tool_result.is_error === true` 최장 연속 길이 — 세션 간 최댓값 |
| `fun.retryScore` | 필터 통과 user 텍스트에서 `/다시|아니|왜/g` 매치 수 |
| `fun.promptStyle.avgLen` / `oneLinerRatio` | user 텍스트 길이(자) 평균 / 줄바꿈 없는 프롬프트 비율 |
| `highlights.sentences` / `highlights.words` | §4 |

- 정규식·임계값은 Day 7 콘텐츠일에 조정 가능 (OQ-001 범위) — 변경 시 이 표만 고친다.
- 판정(유형·등급)은 싣지 않는다 (BR-001).

## 4. 하이라이트 집계 (BR-005) — 2026-08-16 변경: 명대사 발췌 → 최다 사용 문장·단어
- **문장**: 필터 통과 user 텍스트를 줄 단위로 나눠 정규화(공백 압축·양끝 문장부호 제거) → 동일 문장 빈도 집계 → **반복 ≥2회 중 상위 3개** `[text(≤100자 절단), count]`
- **단어**: 공백 분리 토큰 중 2자 이상·숫자/기호만인 토큰 제외 → 빈도 **상위 10개** `[word, count]`. 불용어 최소 목록·조사 처리 여부는 Day 7 콘텐츠일 확정(OQ-001 범위, 무의존성 유지)
- 텍스트에 BR-005 자격증명 패턴 포함 시 해당 항목 제외. 05 크기 상한 초과 시 `highlights` 전체 제거(REQ-CLI-001 AC-2)
- 발췌 시절 규칙(삽질 직후 프롬프트·재시도 어휘 인용)은 폐기 — 인용은 프라이버시 리스크 대비 재미가 불안정(휴리스틱 의존)

## 5. 기능 요구사항 (P0 — AC 4종)
### REQ-CLI-001: 집계·인코딩·URL 출력 (P0)
- **AC-1 (정상):** Given `~/.claude/projects`에 파싱 가능한 세션 ≥1, When 실행, Then §2·§3 규칙으로 05 페이로드 생성 → 06 규약 인코딩 → 터미널에 URL 전체 출력 (CPY-CLI-001~003)
- **AC-2 (검증 실패):** Given 경로 미존재 → ERR-CLI-001 / 파싱 가능 세션 0개 → ERR-CLI-002. Given 인코딩 결과가 05 크기 상한 초과 → `highlights`를 비우고 1회 재인코딩 후 진행
- **AC-3 (서버 오류):** 해당 없음 (네트워크 호출 0)
- **AC-4 (오프라인):** 정상 동작 — 전 과정 로컬. 브라우저가 페이지를 못 받는 것은 웹 범위 (SCR-002 AC-4)

### REQ-CLI-002: 브라우저 오픈 (P0)
- **AC-1 (정상):** Given URL 생성 완료, When 플랫폼별 명령 실행 (§실행 동작), Then 기본 브라우저에서 `/report` 열림, exit 0
- **AC-2 (검증 실패):** 해당 없음 (입력 없음)
- **AC-3 (spawn 실패):** Given 명령 부재·SSH·컨테이너, Then ERR-CLI-003 — URL은 이미 출력됨, exit 0 (실패로 취급하지 않음)
- **AC-4 (오프라인):** 브라우저는 열리되 페이지 로드 실패 — 웹 범위

### 실행 동작
| 단계 | 규칙 |
|---|---|
| 진행 표시 | CPY-CLI-001 (탐색 중) → 파일 수·기간 요약 CPY-CLI-002 |
| 인코딩 | 06 규약. **05 크기 상한 초과 시 `highlights`를 비우고 1회 재인코딩** (OQ-004 실측 후 상한 확정) |
| URL 출력 | URL 형식 `https://scored.kr/report?from=cli#<data>` (06 진입 출처 쿼리). **항상** 터미널에 전체 URL 출력 (브라우저 오픈 실패·SSH·컨테이너 대비) + CPY-CLI-003 |
| 브라우저 오픈 | darwin `open <url>` / linux `xdg-open <url>` / win32 `powershell -NoProfile -Command Start-Process '<url>'`. **cmd `start` 사용 금지** — 8,191자 인자 상한이 페이로드 크기와 충돌. 실패 시 ERR-CLI-003 |
| 종료 코드 | 성공 0 / ERR-CLI-001·002 → 1 / ERR-CLI-003 → 0 |
| 옵션 | 없음 (v1) — `--help`·`--version`만 |
