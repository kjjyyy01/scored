- **구현 기능:** F-001

## 3. 기능 요구사항
### REQ-LAND-001: npx 명령어 복사 (P0)
- **AC-1 (정상):** Given 랜딩, When EL-LAND-002 클릭, Then 클립보드에 명령어 복사 + CPY-LAND-003 토스트 + EVT-LAND-001 발화
- **AC-2 (검증 실패):** 해당 없음 (입력 없음)
- **AC-3 (서버 오류):** 해당 없음 (클라이언트 전용 동작)
- **AC-4 (오프라인/클립보드 불가):** Given 클립보드 API 실패, When 클릭, Then ERR-CLIP-001 — 명령어 텍스트 자동 선택으로 폴백. EVT-LAND-001은 발화 (클릭 의도 측정)

### REQ-LAND-002: 명령어 나에게 보내기 (P0 — 모바일 공유 유입 대응)
- **AC-1 (정상):** Given 모바일 + Web Share API 지원, When EL-LAND-004 클릭, Then 공유시트에 명령어+랜딩 URL 전달 + EVT-LAND-002(`method: share_sheet`)
- **AC-2 (미지원):** Given Web Share API 미지원, When 클릭, Then 클립보드 복사 폴백 + EVT-LAND-002(`method: clipboard`)
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (오프라인):** Given 오프라인, When 클릭, Then 공유시트/클립보드는 로컬 동작이므로 정상 진행
