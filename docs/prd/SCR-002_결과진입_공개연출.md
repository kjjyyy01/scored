- **목적:** 해시 디코딩 → 유형·등급 판정(BR-001) → 공개 연출(재미 장치 v1 유일 — BR-007). `/report` 상태 머신은 08 §상태전이가 SSOT.
- **구현 기능:** F-002

## 3. 기능 요구사항
### REQ-RES-001: 해시 디코딩·판정 (P0)
- **AC-1 (정상):** Given 유효 해시, When `/report` 진입, Then `?from=cli` 유무로 `entry` 결정 → 디코딩(06 규약) → BR-004 즉시 실행(주소창 하이라이트·쿼리 제거) → BR-001 판정 → Revealing 진입 + EVT-RES-001(`entry`) 발화
- **AC-2 (검증 실패):** Given 손상 해시, When 진입, Then ERR-HASH-001 표시 + EVT-RES-003. Given 미지원 버전, Then ERR-HASH-002 + EVT-RES-003
- **AC-3 (서버 오류):** 해당 없음 (디코딩·판정 전부 클라이언트)
- **AC-4 (오프라인):** Given 페이지 로드 완료 후 오프라인, When 디코딩·연출, Then 정상 동작 (전 과정 로컬). 최초 로드 실패는 브라우저 기본 — 범위 외

### REQ-RES-002: 공개 연출 (P0 — 재미 장치)
- **AC-1 (정상):** Given Revealing, When 연출 재생, Then 빌드업(CPY-RES-001) → 지표 6줄 카운트업 → 등급 릴 정지(클라이맥스) → **자연 종료 = EVT-RES-002(`skipped: false`) 발화 + EL-RES-005 표시(대기)** → EL-RES-005 클릭 시 카드 공개(SCR-003). 연출 자체는 총 3~4초 상한, 대기는 무제한 — EVT는 연출 종료 시점에 발화한다(클릭 발화로 바꾸면 대기 중 이탈자가 완주 지표에서 빠져 이전 데이터와 비교가 깨진다)
- **AC-5 (링크 유입):** Given `entry=link`, When Revealing, Then 1.5초 축약판(카운트업 생략, 등급 릴만) + 자연 종료 시 AC-1과 동일한 대기·발화 — 축약도 자연 종료다. 수신자 재방문 마찰 최소화
- **AC-2 (스킵):** Given **연출 중(자연 종료 전)**, When EL-RES-002 클릭 또는 Esc, Then 즉시 성적표 + EVT-RES-002(`skipped: true`). Given **대기 중(자연 종료 후)**, When EL-RES-005 클릭 또는 Esc, Then 카드 공개 — EVT는 이미 발화됐으므로 중복 발화하지 않는다
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (reduced motion):** Given `prefers-reduced-motion`, When Revealing, Then 스테이지를 재생하지 않고 카드 페이드 1종으로 대체 + EVT-RES-002(`skipped: false`) — 연출을 건너뛴 주체가 사용자가 아니므로 스킵이 아니다 (PLAN 축 패스 규칙)

### REQ-RES-003: 데이터 부족 분기 (P0)
- **AC-1:** Given `prompts < 10` (BR-002), When 판정, Then 연출은 축약(등급 릴 생략), 카드는 부분 모드 + CPY-ERR-003
- **AC-2 (검증 실패):** 해당 없음 (분기 조건뿐)
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (오프라인):** 정상 동작 (로컬 판정)

## 15. 접근성
공통 기준 (SCR-001 §15) + 연출 중에도 스킵 버튼 키보드 접근 가능(스테이지 내 유일 focusable — Tab 1회 도달, 포커스 탈취 금지) · Esc도 동일 경로. 자연 종료 후에는 EL-RES-005가 그 자리를 이어받아 **유일 focusable 유지** — Esc도 결과 보기와 동일 경로
