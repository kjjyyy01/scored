## 1. 개요
- **목적:** `/report` 첫 화면 = **스탯 카드**(GitHub Readme Stats 은유): 오늘의 유형 + 등급 뱃지 + 날짜 + 지표 6줄 + 유형 문구. **카드 = 공유 이미지 = OG 동일 구성** — 공유 욕구의 발원지. 아래로 스크롤하면 SCR-004 대시보드 섹션 (2026-08-16 grill로 "성적 매기기"에서 "지표 보여주기+등급"으로 재정의)
- **구현 기능:** F-003

## 3. 기능 요구사항
### REQ-RPT-001: 스탯 카드 렌더링 (P0)
- **AC-1 (정상):** Given 판정 완료 페이로드, When Report 상태, Then EL-RPT-001~003·005~006 표시 + 007/008 중 진입 경로에 해당하는 하나 (REQ-RPT-003) (유형·등급·문구는 BR-001 판정 모듈 출력, 지표는 05 원자료)
- **AC-2 (검증 실패/부족):** Given 데이터 부족 모드 (BR-002 `prompts < 10`), When 렌더, Then 유형·등급 자리에 CPY-ERR-003(재실행 유도) + 산출 가능한 지표 줄만 표시
- **AC-3 (서버 오류):** 해당 없음 (클라이언트 렌더)
- **AC-4 (오프라인):** 정상 동작 (로컬 데이터)
- **AC-5 (지표별 독립 실패):** Given 특정 지표 산출 불가(필드 누락), When 렌더, Then 해당 줄만 생략 — 부분 생성 허용 (MVP 파서 리스크 대응)
- **AC-6 (진행 중):** Given `inProgress: true`, When 렌더, Then EL-RPT-001에 CPY-RPT-002 배지 (`generatedAt` 로컬 HH:MM)

### REQ-RPT-002: 카드 이미지 원본 (P0)
- **AC-1:** Given Report 상태, When SCR-005가 카드 이미지를 생성, Then EL-RPT-001~003과 **동일 구성·동일 값**을 렌더 (한 컴포넌트를 화면·이미지 둘 다에 사용 — 값 복제 금지)
- **AC-2 (부족):** 부분 모드면 유형·등급 없는 변형 (SCR-005 엣지 3)
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (오프라인):** 정상 (로컬 렌더)

### REQ-RPT-003: 공유 수신자 유입 CTA (P0)
> 근거: 도달률 분모가 `users(page_view, /)`인데(15 §계산식) 공유 링크 수신자는 `/`를 거치지 않는다. 이 CTA가 없으면 공유가 유입으로 전환되지 않아 표본 조건(데스크톱 150명)이 위태롭다.
- **AC-1 (링크 유입):** Given `entry=link`, When Report 상태, Then EL-RPT-008 표시 — 클릭 시 `/?from=report`로 이동
- **AC-2 (CLI 유입):** Given `entry=cli`, When Report 상태, Then EL-RPT-008 **미표시** (자기 성적표 화면의 노이즈 제거 — CPY-DASH-001과 동일한 조건부 패턴)
- **AC-2b (상보 관계):** EL-RPT-007과 EL-RPT-008은 배타적이다 — `entry=cli`면 007만, `entry=link`면 008만. 둘 다 "다음 행동" 유도이며 대상이 다르다
- **AC-3 (부족 모드):** Given BR-002 부분 모드 + `entry=link`, When 렌더, Then EL-RPT-008 표시 (판정 여부와 무관 — 유입 동선은 항상 열려 있어야 한다)
- **AC-4 (오프라인):** 링크만 렌더 (이동은 네트워크 필요 — 기본 동작)
