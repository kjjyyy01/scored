## 1. 개요
- **목적:** 재미 축 본체 — 유형·등급·재미 지표·유머 코멘트·하이라이트를 성적표 형태로 표시. 공유 욕구의 발원지.
- **구현 기능:** F-003

## 3. 기능 요구사항
### REQ-RPT-001: 성적표 렌더링 (P0)
- **AC-1 (정상):** Given 판정 완료 페이로드, When Report 상태, Then EL-RPT-001~003 표시 (지표 값·문구는 BR-001 판정 모듈 출력)
- **AC-2 (검증 실패/부족):** Given 데이터 부족 모드 (BR-002), When 렌더, Then 유형·등급 영역에 CPY-ERR-003 + 산출 가능한 지표 카드만 표시
- **AC-3 (서버 오류):** 해당 없음 (클라이언트 렌더)
- **AC-4 (오프라인):** 정상 동작 (로컬 데이터)
- **AC-5 (지표별 독립 실패):** Given 특정 지표 산출 불가(필드 누락), When 렌더, Then 해당 카드만 생략 — 부분 생성 허용 (MVP 파서 리스크 대응)

### REQ-RPT-002: 하이라이트 표시 (P1)
- **AC-1:** Given `highlights` 존재, When 렌더, Then EL-RPT-004 표시 — 문장은 "\"커밋해줘\" ×47" 형식, 단어는 빈도순 태그 (BR-005 상한은 CLI가 보장 — 웹은 방어적으로 문장 3·단어 10·100자 절단)
- **AC-2:** Given `highlights` 없음/컷, When 렌더, Then 영역 미표시 (빈 껍데기 금지)
