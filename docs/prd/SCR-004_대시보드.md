## 1. 개요
- **목적:** 실용 축 — 토큰·활동·도구 통계. 재미를 빼도 서비스가 서게 하는 기둥 (MVP 한 줄 가치).
- **구현 기능:** F-004 (P1 — **Day 9 컷 4순위**: 컷 시 SCR-003 내 숫자 카드 4개로 격하)

## 3. 기능 요구사항
### REQ-DASH-001: 통계 렌더링 (P1)
- **AC-1 (정상):** Given 페이로드, When Dashboard 상태, Then EL-DASH-001~004 렌더 (전부 로컬 계산)
- **AC-2 (부족/부분):** Given 데이터 부족(BR-002) 또는 필드 누락, When 렌더, Then 산출 가능한 위젯만 표시 + CPY-ERR-003 (지표별 독립 실패)
