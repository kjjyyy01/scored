## 1. 개요
- **목적:** `/report` **하단 섹션**(SCR-003 카드 아래로 스크롤, 탭 아님 — 2026-08-16) — 실용 축: 대상일 24h 타임라인, 7일 추이·히트맵, 도구·모델, **프롬프트 섹션**(통계 + 자주 쓴 문장·단어), 로컬 대화 리포트 안내. 재미를 빼도 서비스가 서게 하는 기둥.
- **구현 기능:** F-004 (**P0** — 컷 대상 제외)

## 3. 기능 요구사항
### REQ-DASH-001: 통계 렌더링 (P0)
- **AC-1 (정상):** Given 페이로드, When SCR-004 섹션 노출, Then EL-DASH-001~004·006 렌더 (전부 로컬 계산) + 첫 노출 시 EVT-DASH-001
- **AC-2 (부족/부분):** Given 데이터 부족(BR-002) 또는 필드 누락, When 렌더, Then 산출 가능한 위젯만 표시 (지표별 독립 실패, 빈 껍데기 금지)
- **AC-3 (서버 오류):** 해당 없음 (전부 로컬)
- **AC-4 (오프라인):** 정상 동작 (로컬 데이터)

### REQ-DASH-002: 로컬 대화 리포트 안내 (P0)
- **AC-1 (정상):** Given `entry=cli`, When 렌더, Then EL-DASH-007 표시 (경로는 관례 문자열 — 페이로드에 경로 없음, 05)
- **AC-2 (링크 유입):** Given `entry=link`, Then EL-DASH-007 미표시
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (오프라인):** 정상
