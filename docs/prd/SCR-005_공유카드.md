## 1. 개요
- **목적:** 공유 트리거 — 카드 이미지 저장·링크 복사·동적 OG. 킬 크라이테리아 2번 지표(공유·저장률)의 발생 지점. `/report` 내 오버레이(공유 시트).
- **구현 기능:** F-005

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
|---|---|---|---|---|
| EL-SHARE-001 | 카드 미리보기 | 캔버스/이미지 | Y | 유형·등급·요약 스탯 요약 카드 |
| EL-SHARE-002 | 카드 저장 버튼 | 버튼 | Y | CPY-SHARE-001 — 다운로드 + 클립보드 |
| EL-SHARE-003 | 링크 복사 버튼 | 버튼 | Y | CPY-SHARE-002 |
| EL-SHARE-004 | 하이라이트 포함 토글 | 토글 (기본 OFF) | N | `highlights` 존재 시만. CPY-SHARE-003, BR-004 |
| EL-SHARE-005 | OG 범위 고지 | 안내 문구 | Y | CPY-SHARE-004 (MVP 데이터 흐름 5 고지 의무) |

## 3. 기능 요구사항
### REQ-SHARE-001: 카드 이미지 저장 (P0)
- **AC-1 (정상):** Given 카드 생성 완료, When EL-SHARE-002 클릭, Then PNG 다운로드(모바일: 공유시트) + EVT-SHARE-002
- **AC-2 (생성 실패):** Given 이미지 생성 실패, When 클릭, Then ERR-IMG-001 — 재시도 + 링크 복사 대안
- **AC-3 (서버 오류):** 해당 없음 (클라이언트 캔버스 렌더)
- **AC-4 (오프라인):** 정상 동작 (로컬 렌더)

### REQ-SHARE-002: 결과 링크 복사 (P0)
- **AC-1 (정상·하이라이트 제외):** Given 토글 OFF(기본), When EL-SHARE-003 클릭, Then 하이라이트 제거 해시 URL 복사 + EVT-SHARE-003(`highlight_included: false`)
- **AC-2 (하이라이트 포함):** Given 토글 ON, When 클릭, Then 하이라이트 포함 해시 URL 생성·복사 + EVT-SHARE-003(`highlight_included: true`) — BR-004의 유일한 하이라이트 포함 URL 생성 지점
- **AC-3 (서버 오류):** 해당 없음
- **AC-4 (클립보드 실패):** ERR-CLIP-001 — URL 텍스트 노출 폴백

### REQ-SHARE-003: 동적 OG 링크 (P0 — 2026-08-16 컷 제외)
- **AC-1 (정상):** Given 링크 복사 시, When URL 생성, Then OG 쿼리(07 파라미터, BR-006 범위) 포함 URL 생성 — 쿼리 생성은 이 시점뿐 (MVP 데이터 흐름 5)
- **AC-2 (실패):** Given `/api/og` 실패, Then 정적 OG 폴백 (ERR-OG-001) — 링크 공유 자체는 항상 동작
- **AC-3 (서버 오류):** = AC-2
- **AC-4 (오프라인):** 링크 생성은 로컬 — 정상. OG는 수신자 측 크롤러가 호출
